# QuantaryX Technologies 靜態網站 / Static Website

## 專案簡介 (Project Overview)

QuantaryX Technologies 是一家專注於資產管理與人工智慧的金融科技公司。本靜態網站用於展示公司產品、解決方案與企業資訊，支援繁體中文、簡體中文與英文。網站內容涵蓋智慧金融、合規性、模組化設計等主題，專為專業金融機構設計。

QuantaryX Technologies is a fintech company focused on asset management and artificial intelligence. This static website showcases our products, solutions, and company information, supporting Traditional Chinese, Simplified Chinese, and English. The site covers intelligent finance, compliance, modular design, and is tailored for professional financial institutions.

## 開發環境設置 (Development Setup)

1. 下載專案 (Clone the repository):
   ```sh
   git clone https://github.com/Flamestone-Capital/QuantaryX.git
   cd QuantaryX
   ```
2. 安裝相依套件 (Install dependencies):
   ```sh
   npm install
   ```
3. 啟動開發伺服器 (Start development server):
   ```sh
   npm run dev
   ```
   預設會在 http://localhost:5173 或終端機顯示的網址開啟。

---

## 建置與預覽 (Build & Preview)

- 建置靜態檔案 (Build static files):
  ```sh
  npm run build
  ```
- 本地預覽建置結果 (Preview build locally):
  ```sh
  npm run preview
  ```
